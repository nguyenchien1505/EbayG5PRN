# H02 — Hồ sơ feedback và khối About this seller

Status: Done
Dependency: H01
Requirement IDs: G5-01; G5-04; G5-05; UI-01

## Mục tiêu và phạm vi

- Hồ sơ `/Sellers/Feedback/{id}` theo F2 (classic desktop) và F2m (mobile): thẻ seller (avatar, tên, điểm + sao, %, Member since), Feedback ratings, Detailed seller ratings, tab All received / Received as buyer / Received as seller / Left for others, ô tìm theo tên hoặc số item, Period, Sort (Most relevant / Most recent), cột FEEDBACK / FROM / WHEN kèm điểm buyer, phân trang + items per page, Member Quick Links.
- Trang sản phẩm: khối About this seller + Seller feedback theo SA và IT-4 (Visit store, Message seller, Save seller, Detailed seller ratings, Popular categories, danh sách feedback có lọc, See all feedback). "Usually responds within …" tính từ dữ liệu chat.
- Tab hoặc nút thuộc tính năng chưa có (feedback cho buyer, Save seller, store) xử lý theo ADR-003 §2. Member since cần nguồn dữ liệu thật (cột mở rộng), không suy diễn.
